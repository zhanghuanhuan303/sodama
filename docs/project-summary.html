02 · 工程历程（阶段）

阶段内容验收/产出
K0–K3 内核攻坚 dae eBPF 数据面源码级研究（反汇编+逐函数移植）；规则 VM 逐字节对拍；数据面 Rust 化（aya-ebpf/BTF） 8 程序/14 map；规则对拍逐字节一致；C 数据面退役（ADR-0025）；lab 拓扑/verify 夹具成型
P3–P33 功能与生态 分流主链路（domain/sip/dip/port/pname/mac/dscp）；DNS 子系统（缓存/路由/DoT/DoH h2+h3/DoQ/ECS）；12 协议家族 + shadow-tls；订阅/节点组/健康检查/粘滞 IP；嗅探+dial_mode+sniff-punt（TLS/HTTP/QUIC）；IPv6 TCP+UDP 全链；真网关模式；运维状态面 lab 专项全绿；真机浏览器验收（YouTube 200 / 出口 IP 正确）；订阅#1（50×vless-ws）与订阅#2（REALITY+Vision / anytls）真实节点可用
M1–M4 性能 M1 splice 零拷贝（Direct/VLESS 明文）；M2 kTLS 内核 TLS + TLS 上 splice；M3 Vision-over-TLS（双向 XTLS DIRECT）；M4 epoll worker 池（每连接 0 线程）+ offload 看门狗单线程 vless 12.2→16.9 Gbps / CPU 380→60 ms；relay 8 流 21.6 Gbps；TLS memcpy 29.4%→1.6%；10k 连接 28→29 线程 / 34.8 MB（线程模型 527 MB）；风暴 26k/s
O3–O10 专项优化 O5 printk 门控；O6 AEAD 实测定调（chacha 保留）；O7 UDP recvmmsg/sendmmsg + 分片会话表；O8 缓冲池（按字节封顶 8MB）+ 有界优雅退出 + 30s trim；O9 kTLS；O10 vision 20k pps 0 丢包 CPU 580 ms/40k 包（五方最低）；退出整机 462 ms 无残留；churn 300 条 RSS 无增长
G1 真实口径 真实订阅节点/公网基准（sodama/dae/sing-box 共用同一节点与固定后端 IP；v2ray 无 REALITY 显式 skip）；CPU 计量升级 ns 级 schedstat 17 轮/实现：CPU/GB 6233 vs 8820 / 8557；文档 P5/06c 节；工具 real.sh/probe-node* 入库
内存终测 五方五阶段（idle→吞吐→hold2000→churn→静置回收），新纳入 mihomo（Clash Verge 内核） 五阶段全部最低（见 05 节）；独立报告 docs/memory-report.html
OpenWrt P0 应用侧完成，内核冒烟暂停 musl 静态交叉构建三架构；ipk 包（procd/uci/数据面对）；内核 fragment；QEMU 自动冒烟 官方内核缺 CONFIG_NAMESPACES（实测确认，dae 同样依赖）；自编内核镜像冒烟移至后续（cmake bootstrap 宿主补丁已定位）

03 · 架构总览

数据面（eBPF，全 Rust）

组件要点
程序/hook7×TC + sk_skb；TCX 挂载（退出自动摘除）；LAN ingress / WAN egress+ingress / dae0 / dae0peer / 单臂 dual-role
分流 VMdomain/sip/dip/sport/dport/l4proto/ipversion/dscp/pname/mac + fallback + 逻辑与或非 + must；epoch 双槽热重载
透明代理tproxy v4/v6；sockmap offload；UDP 批量 + 16 分片会话表
DNS/嗅探DNS 接管与 dns.routing；TLS/HTTP/QUIC SNI 嗅探（用户态 MSG_PEEK，不消费字节）
进程名cgroup2 钩子 6/6（connect4/6、sendmsg4/6、sock_create/release）

控制面（用户态 Rust）

组件要点
relay/reactorepoll worker 池；字节透明链路 splice 零拷贝；codec 会话入池（VLESS 全组合/Trojan/vmess/ss 系/anytls）
TLS/REALITY/Visionrustls（ring）+ 自实现 REALITY/Vision（XTLS DIRECT 双向）；kTLS 实验开关；ws/wss
协议栈12 家族 + shadow-tls 插件：vless/vmess/trojan/ss/ss2022/ssr/hysteria2/tuic/juicity/naive/shadow-tls/anytls
路由/组/DNS订阅/组/健康检查/粘滞 IP；DNS 缓存/路由/加密上游/ECS
资源治理缓冲池封顶 8MB；UDP 槽按需；30s malloc_trim；SIGTERM 有界退出

运维面

Unix socket 状态面（status/rules/config/maps/metrics/reload/suspend/resume）、Prometheus 文本导出、sysdump/trace、 日志文件轮转（SIGHUP reopen）、启动自检与失败自动回滚（真网关一键脚本）。

1 客户端LAN/WAN 钩子（TCX）
2 分流 VM规则命中 → proxy/direct/block
3 控制面对dae0 veth + tproxy（netns daens）
4 relay/reactorsplice / codec / offload
5 节点协议栈 + 真实出口
