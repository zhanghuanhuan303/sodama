## 2. sing-box 1.14 源码事实：嗅探结果无法回写拨号目标

对照源码 `SagerNet/sing-box@v1.14.2`（安装版 `sing-box version 1.14.2`）：

| 位置 | 事实 |
|---|---|
| `option/rule_action.go` | `type RouteActionSniff struct { Sniffer badoption.Listable[string]; Timeout badoption.Duration }` —— sniff action **只有** `sniffer` 与 `timeout` 两个字段 |
| `option/inbound.go:73` | `SniffOverrideDestination bool \`json:"sniff_override_destination,omitempty" schema:"omit"\``，位于 `// Deprecated: Use rule action instead` 的 `InboundOptions`；`schema:"omit"` = 已从 schema 移除 |
| `route/rule/rule_action.go:516` | `RuleActionSniff.OverrideDestination bool  // Deprecated`；`NewRuleAction()` 构造该结构体时只赋 `SnifferNames`/`Timeout`，**该字段在 1.14.2 中从不被赋值** |
| `route/route.go:367/754/878` | 仅在 `if action.OverrideDestination && M.IsDomainName(metadata.Domain)` 时把 destination 改写成嗅探到的域名；因上一层永不置位，**1.14 中嗅探不会改写拨号目标** |

实测：`sing-box check` 对以下写法均报 `json: unknown field`
（`route.sniff_override_destination` / rule 级 / `action: "sniff"` 内联 `override_destination`）。
`action: "route"` + `override_address: "<域名>"` 合法且生效（`badoption.Addr` 支持域名）——
本轮 sing-box 即用此法出域名，并保留 sniff 规则以对齐嗅探工作量。

结论：sing-box ≥1.11 起，透明代理场景「嗅探域名 → 回写拨号目标」的能力被移除且无等价 rule action；
生产上只能靠 FakeIP（DNS 劫持 + fake-ip 反查）或 `override_address` 静态指定。

## 3. worker 只接受域名目标（上一轮实测）

- 以 IP 为 VLESS 目的地拨出时，worker 直接回收连接（WS Close 帧 `\x88\x00`，无 HTTP 响应）。
- 三方实现因此均必须「嗅探 SNI/Host → 域名拨号」；sodama 用 `--dial-mode domain+`
  （`domain` 严格档对未知域名首连会按 IP 拨出，故取 `domain+`），dae 用 `dial_mode: domain+`。

## 5. 出口池抖动的量化（v2ray 参考客户端，目标 proof.ovh.net/files/10Mb.dat）

- **默认 8 出口路径**（原始订阅 path），固定边缘 `203.0.113.123:2053`：
  20 轮 → 完整 **3**、截断 **17**（`rc=56 OpenSSL SSL_read: … unexpected eof while reading`，
  体积 16 KB–1.5 MB，耗时 2.3–3.0 s）。
- 换 CF 边缘（`203.0.113.93:2096` / `203.0.113.147:2087` / `203.0.113.232:2083` / `203.0.113.121:2053`）
  仍间歇截断（各 2–4 轮中 1–2 轮失败）→ **不是单一边缘问题**，出口池中部分出口不可用。
- **单出口路径**（`path=/proxyip=<单 IP>`）逐一探测 8 个出口 ×2 轮：
  `203.0.113.79` 2/2、`203.0.113.244` 2/2、`203.0.113.68` 2/2（2.41/2.42 MB/s）、
  `203.0.113.236` 2/2；`203.0.113.145`、`203.0.113.214` 0/2；`203.0.113.215`、`203.0.113.61` 1/2。
- 固定健康出口后再测 4 轮：3/4 完整（残余 ~25% 为节点侧固有抖动）→ 脚本以「短传输判失败 + 每轮
  最多 6 次重试」消化。
