# ADR-0010：K2 交付边界——对拍以「编译产物逐字节一致」为准，内核矩阵按可用内核执行

- **状态**：已采纳（2026-10-03）
- **对应**：ADR-0009 的 K2（对拍与内核矩阵）
- **相关**：ADR-0002（数据面语言）、ADR-0009（K 轨道）

## 背景

ADR-0009 给 K2 的验收是「map dump/判决对拍自动化；内核矩阵（5.17/6.1/6.6/6.14+）；
故障注入；矩阵全绿、与 Go 版同规则集产出可对齐」。实际执行时有两处与环境有关的边界：

1. **对拍的可行边界**：完整运行 Go 版 dae 需要 bpf2go 生成物 + 完整控制面 + 真实
   网卡拓扑，成本远高于本阶段所需；但 dae 的规则编译路径（`pkg/config_parser` →
   `component/routing` → `control.RoutingMatcherBuilder`）可以在 `dae_stub_ebpf`
   构建下离线驱动，产出「即将写进 BPF map 的 match_set 数组与 LPM 前缀」。
2. **内核矩阵的可行边界**：本环境网络受限且本机只有两个内核可用
   （宿主 6.18.54-lts、镜像内核 7.2.8）。5.17 / 6.1 / 6.6 / 6.14+ 的内核镜像无法获取，
   无法在本机执行。

## 决策

1. **对拍口径**：K2 的「对拍」= **编译产物逐字节一致** —— 同一份 `.dae` 子集规则，
   dae 原版 Go 编译器与 sodama 的 Rust 编译器输出的 `match_set` 数组（字段级：
   type/not/outbound/mark/must/端口区间/掩码/LPM 前缀集合）必须逐字节一致，由
   `lab/parity.sh` 自动化。**判决对拍**由 `lab.sh verify` 的包级 e2e 承担（判决结果
   与 dae 常量、语义注释对齐）。**完整 Go 运行时对拍**（跑真实 dae 打同一条流）不列为
   K2 验收项，留待 K3 生态接入阶段按需评估。
2. **内核矩阵口径**：交付 `lab/matrix.sh`（`run` 在任意内核上原生跑；`vm` 用 QEMU +
   9p root 引导第二内核），并在**本环境可用的内核集合上全绿**作为 K2 验收。
   `5.17 / 6.1 / 6.6 / 6.14+` 的覆盖列为**未执行项**（不宣称已实测），待有多内核
   宿主/虚拟机时用同一脚本补跑，不阻塞 K3。
3. 未覆盖风险必须显式记录：<6.6 的 netlink 附加路径、<5.17 的加载失败诊断，
   均未在真机验证（见 `lab/matrix/SUMMARY.md`）。

## 理由

- 规则编译是 ABI 风险最集中的一层（枚举编码、粘性 OR/AND、LPM 下标与前缀编码、
  must/mark 放置）；编译产物逐字节一致直接覆盖这一类风险，且**不需要 root、可在 CI 跑**。
- 判决语义风险（`bpf_loop` 求值顺序、conn_state 缓存、重定向/回程）由包级 e2e 覆盖，
  这些用例本身就是按 dae 语义注释设计的。
- 在内核矩阵上，脚本化交付比「凑一个旧内核」更有长期价值：换内核不改代码，
  `check` 会按版本打印能力门槛与预期差异。

## 后果

- 正面：对拍可持续（改规则编译器即跑即比）；矩阵可扩展（任何内核一个命令）；
  未覆盖项被诚实记录而不是隐含在「全绿」里。
- 负面/代价：与 Go 运行时的端到端一致性没有直接被证明，只被「编译产物一致 +
  语义按源码移植 + e2e 断言」间接支撑；旧内核（<6.6）的钩子生命周期语义未实测。
- 若 K3 需要，可在「Go 当协议后端」过渡形态下补做运行时对拍。

## 验证方式（实测）

- `lab/parity.sh`：`rules.dae`、`rules.reload.dae` 两份规则集与 dae 原版编译输出
  **逐字节一致**（9 行/份；dae 侧用 `dae_stub_ebpf` 构建驱动真实 builder，见
  `lab/parity/README.md`）。
- `lab/matrix.sh`：宿主 6.18.54-2-lts 与 QEMU 7.2.8-arch1-2 均为 **8/8 PASS**
  （证据与命令见 `lab/matrix/SUMMARY.md`）。
- 故障注入两项：kill -9 后 TCX 自动摘钩 + 流量 fail-open 到内核直转；
  10 轮 reload 打流全部成功、无「热重载失败」。
- 单写者：竞争发布者在 2s 窗口内被拒（计数 +1、绑定保持），陈旧窗口后允许改绑且
  回程恢复（`lab.sh test-rebind`）。

## 修订条件

获得 5.17/6.1/6.6 内核环境后补跑矩阵；若出现「编译产物一致但判决不一致」的情形，
本 ADR 的对拍口径升级为运行时对拍并新写 ADR 记录。
